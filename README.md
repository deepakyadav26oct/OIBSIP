# BMI Calculator

## 📌 Project Overview

BMI Calculator is a Python-based application developed as part of the Oasis Infobyte Python Programming Internship.

The application takes the user's weight and height as input, calculates the Body Mass Index (BMI), and displays the corresponding BMI category.

## 🛠️ Technologies Used

- Python
- Functions
- Conditional Statements
- Exception Handling
- Input Validation

## ✨ Features

- Accepts weight in kilograms
- Accepts height in meters
- Calculates BMI
- Displays BMI rounded to 2 decimal places
- Classifies BMI into:
  - Underweight
  - Normal
  - Overweight
  - Obese
- Handles invalid input
- Handles negative values
- Allows the user to calculate BMI again without restarting the program
- Provides a clean command-line interface

## 📐 BMI Formula

```
BMI = Weight / (Height × Height)
```

## 📊 BMI Categories

| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal |
| 25 – 29.9 | Overweight |
| 30 or above | Obese |

## ▶️ How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Open the project folder

Open `Python-Task2-BMICalculator` in VS Code.

### 3. Open the terminal

Run:

```
python bmi_calculator.py
```

### 4. Enter the details

Enter:

- Weight in kilograms
- Height in meters

The application will calculate and display the BMI.
